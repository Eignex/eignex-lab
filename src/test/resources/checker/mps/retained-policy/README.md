# Retained MPS policy controls

Original Bell3a and Egout bytes are from the public [MIPLIB 3 archive](https://miplib2010.zib.de/miplib3/miplib3.tar.gz), distributed for academic research. They match the retained model digests:

- Bell3a: `1ada0bcc162defc9d8f17769920d3531d6e9f8c69f466e3eb165939ae845fd43`
- Egout: `351ed046eb56e07662b3c2dba35800f5d2cee3fac18c1bd7fbc8dea4a0dcd8db`

The four JSON fixtures retain complete witness bytes, exact objective text, source and build identities, original strict rejection receipts and authenticated HTTP artifact paths from Bell3a job 10051 case 0 and Egout job 10028 cases 4, 7 and 8. `origin` identifies the original native record and frozen handoff by SHA-256. Records and retained rejections are never rewritten.

Historical records lack machine-readable numerical semantics and remain unqualified. `supplementalSemantics` is a separate conditional replay policy reconstructed from the named source revisions and retained commands; its provenance includes source-file and CLI/library binary hashes. It does not manufacture a declaration on the historical record. The policy checks original decimal source rows and bounds with slack `max(abs, relative * scale)`, exact integrality and exact objective equality; row scale uses the bound magnitude and sum of absolute term activities. Both the zero-tolerance verdict and conditional policy verdict are retained. Neither establishes optimum authority or performance benefit.
